# 晴绘卡渲 / QingHui Toon 1.0

Blender 5.1 / Eevee 独立卡渲工具。安装 ZIP 后在三维视图 N 面板使用「晴绘卡渲」。

- 原创二段、三段、连续明暗；独立对比度和亮部保护。
- 本机 MiaoBox 手动光照、蓝影、红影兼容；原资产由使用者在本机提供。
- 通用参数、内部饱和度和色带控制；多个材质整套风格导入导出。
- 原材质备份、共享网格和材质隔离、旧材质迁移与还原。

模块：shaders.py 为原创着色算法；materials.py 管理材质与本机兼容；presets.py 管理参数文件；geometry.py 管理描边；ui.py 为中文面板和操作。

源码使用 GPL-3.0-or-later。安装包没有 MiaoBox 的代码、节点库或用户的模型、贴图。
