# 晴绘卡渲 1.0

默认风格强调明亮环境、适中的人物对比，以及肤色和浅色服装的亮部保护。

本插件提供独立的卡渲调节工作流。内置二段、三段和连续明暗三种算法，也能使用本机已有的 MiaoBox 手动光照、蓝阴影和红阴影节点库。

## 打开工程后

打开自己的 Blender 工程，在三维视图按 **N → 晴绘卡渲**，指定网格或骨架，默认风格为「明亮日系 · 参考增强」。

安装并启用后可使用晴绘面板。旧节点无需删除；先在工程副本中检查转换与还原。

## 最常用的调整

1. **选择范围**：全部材质，或当前材质。材质列表中选「衣料」「头」「头发」，可以分别调节。
2. **色彩对比**：增加人物明暗差距。当前默认衣料 1.40、头发 1.12、肤色 1.08。它们针对贴图亮度调整，数值不是屏幕对比度的百分比。
3. **亮部保护**：默认开启。增加对比时，尽量保住脸和白衣服的亮度；关闭后可以让亮部也随对比变亮。
4. **阴影深度 / 边界柔度**：分别控制阴影深浅和分层边缘。想保留颜色、只加强立体感，先调整这两项。
5. **工程整体控制**：一起调整本文件中的晴绘材质。这里也可以切换 Standard、AgX、场景曝光。场景显示影响整个厨房；当前材质的调色只影响对应材质。

描边在示例工程中默认关闭，更接近参考图；展开「描边」即可开启，调节线宽和墨色。

## 不同工程使用不同卡渲

| 方式 | 适合的效果 |
|---|---|
| 三段卡渲 | 明亮日系，保留浅阴影与中间调 |
| 二段赛璐璐 | 更明确的亮暗分区 |
| 连续明暗插画 | 柔和、偏插画的体积感 |
| 本机 MiaoBox · 手动光照 | 使用原节点库的灯光响应与质感参数 |
| 本机 MiaoBox · 蓝 / 红阴影 | 使用原节点库的虚拟光影效果 |

**应用风格** 会更新所选材质的参数。勾选「同时更新工程整体与色彩显示」，也会应用该风格推荐的全局参数和场景显示。

**切换方式，保留通用参数** 用来比较算法：保留颜色、对比度等通用设置。MiaoBox 的专属参数按所选节点库初始化；想完整保留一种方式的调参，先保存风格。

内置「明亮日系」「清晰赛璐璐」推荐 Standard；「柔绘插画」推荐 AgX。不同工程仍可自行选择显示方式，不会强制锁定。

## MiaoBox 兼容模式

首次选择本机方式时，指定 `Miaobox_免费卡渲_250122` 文件夹，随后点「切换方式」。本机已有路径已填入示例工程，无需手动追加 NodeTree。

- 当前材质面板可直接调原节点的贴图提亮、阴影、不透明度、质感、金属及虚拟光影角度等参数。
- 内部固定饱和度已开放；「本机节点 · 阴影色带」可以编辑内部色带及过渡。
- 每个材质使用独立的本机节点副本，修改内部参数不会连带修改其他材质或原始节点库。
- 晴绘的亮部保护作用于外层调色。MiaoBox 内部的贴图提亮、发光等参数仍可能把亮部推高，需要在本机参数中分别调整。

插件本身包含新写的代码与三种原创算法；MiaoBox 兼容模式读取你本机的既有节点库，安装包不包含该节点库。兼容示例图使用了 MiaoBox 节点：**渲染：MiaoBox**。

## 保存、读取、还原

**保存风格** 会记录当前范围内的多个材质，包括卡渲方式、颜色、阴影、MiaoBox 专属参数、内部饱和度、色带，以及工程整体和显示设置。不会包含人物贴图或模型。

**读取风格** 优先匹配材质名称，其次按肤色、头发、衣服等类型匹配。因此可在另一个工程里复用。名称和类型都无法匹配时，先手动指定材质类型并应用一次。多个同类型材质可以先统一读取，再单独细调。

读取时，只有勾选「同时载入工程整体与色彩显示」，才会改变其他晴绘材质共享的整体设置与场景显示。

**还原所选范围** 会找回应用前保留的原材质，支持原材质改名后的还原。还原全部材质会移除晴绘描边；最后一个晴绘材质还原后，会恢复最初的渲染引擎与显示设置。不要手动删除作为备份的原材质。

安装包、构建清单和 SHA-256 清单位于 GitHub 的 QingHui-Toon Release。用户工程、人物素材、第三方节点库和原案例预览不随公共版本发布。源码见仓库中的 qinghui_toon 目录。

## 适用范围

使用 Blender 5.1 的 Eevee。自动转换支持 MMD Tools 基础材质、直接接到输出的 Principled、旧 MiaoBox 和上一版柔色材质；不支持的复杂混合材质会保留并提示。MMD 的球面贴图、原高光、凹凸和次表面效果不会完整迁移，玻璃、金属和水等可继续使用原材质。

节点已经保存在工程里，渲染不依赖控制面板插件。原创节点库也不包含人物或厨房资产。完整动画工程保留用户原有资产。

本插件负责材质与显示设置；动画、物理及出片应按各工程自身范围另行检查。
