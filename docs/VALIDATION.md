# 晴绘卡渲 1.0.0 验证边界

2026-10-09 本轮使用 Blender 5.1.2、工厂设置、隔离后台进程执行 `tests/core_test.py`，输入为程序创建的基础网格和材质，无用户人物素材或第三方资产。

通过的行为：

- 共享网格与原材质隔离，未选中对象保持原材质。
- 重复应用保持同一材质；二段、三段、连续方式切换保留色彩对比调节。
- 已有卡渲材质的局部编辑隔离；描边重复应用不增生。
- 原材质改名后准确还原，最后一个卡渲使用者还原后恢复引擎与显示设置。
- 对象级材质槽正确转换和还原。
- JSON 参数往返；非法数值在材质变更前拒绝。
- 缺失 MiaoBox 库时明确失败并保留原材质；复杂材质和空槽保留并提示。
- 三种原创方式均完成真实 Eevee PNG 渲染，节点保存后重开可用。
- 保留 24 / 1.001 的分数帧率与负帧预览；注册、卸载、重注册。

三张基础网格图仅用于渲染冒烟检查；平面受光一致时三种方式可能显示相似，不能据此宣称完整风格视觉验收。

历史案例中曾在人物厨房工程验证卡渲调节、本机 MiaoBox 兼容、连续动画与参数预设。本轮没有重做该工程的视觉验收，没有验证第三方节点库或当前前台窗口，也未验证 Cycles / Blender 5.2。

本轮发行包采用允许清单，仅包含 6 个 Python 模块、许可证和两份说明。发布后需从 Release 实际下载 ZIP、构建清单和 SHA-256 清单，核对大小与摘要；上传成功不能替代下载校验。
